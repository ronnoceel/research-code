# research-code

Analysis code for my research projects. Each subdirectory is a self-contained project and is a
companion to its paper.

Case-level data from restricted registries (e.g., ACS-NSQIP, SEER) is **never** stored here —
those data are governed by Data Use Agreements that prohibit redistribution. Only code is
shared; results are regenerated by running it.

## Projects

- `nsqip-freeflap-frailty-replication/` — replication of Jubbal et al. on age and free-flap
  outcomes (ACS-NSQIP 2022–2024).
